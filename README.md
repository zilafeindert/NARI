# NARI

NARI es un proyecto local de asistente/agente personal para Windows.

## Actualizaciones
La aplicación consulta la información de versión del repositorio y puede descargar el archivo de actualización correspondiente.

## Estructura
- core local
- voz y escucha
- visión de pantalla
- automatización de teclado/mouse
- memoria persistente
- perfiles de juego

Este repositorio es la fuente de distribución de NARI.
